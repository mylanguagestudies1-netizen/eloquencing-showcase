# Eloquencing Showcase

Presentación cinematográfica de las herramientas top de Eloquencing (Next.js 16 + framer-motion).

- `/` — v1 (la favorita, estilo Euphoria/HBO)
- `/v2` — v2 (port Morph del pptx)

Los links a herramientas apuntan a la app principal (`NEXT_PUBLIC_APP_URL`, por defecto https://eloquencing.up.railway.app).

```
npm install && npm run dev
```
